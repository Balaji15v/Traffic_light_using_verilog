# Traffic_light_using_verilog
Designed a Verilog-based traffic light controller for a three-way intersection using a synchronous FSM.
The system manages traffic flow through distinct states, including Green, Yellow, and Red cycles, with
the integrated timing logic achieved via a custom clock divider. I verified the hardware logic through
RTL simulation to ensure safe, conflict-free transitions and reliable state sequencing for real-time
traffic management.
